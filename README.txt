Happy Trip Holiday — ชุดเว็บไซต์พร้อมใช้งาน

ภายในโฟลเดอร์:
- index.html
- assets/ (โลโก้ รูปรถ และรูปโปรแกรมทัวร์)

วิธีทดสอบ:
1. ดับเบิลคลิก index.html
2. เว็บไซต์จะเปิดใน Safari

วิธีอัปโหลดขึ้น GitHub:
1. เข้า Repository HappytripHoliday
2. Add file > Upload files
3. ลากทั้ง index.html และโฟลเดอร์ assets ลงไป
4. กด Commit changes
5. รอประมาณ 1–2 นาที แล้วรีเฟรชเว็บไซต์
